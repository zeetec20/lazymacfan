# Changelog

All notable changes to this project will be documented in this file. See [standard-version](https://github.com/conventional-changelog/standard-version) for commit guidelines.

## 0.1.0 (2026-09-29)

### Features

* Initial release of lazymacfan
* Interactive OpenTUI terminal user interface with fan control, real-time telemetry, and curve editor
* Background daemon agent with AppleSMC hardware control and safety guardian
* Universal native macOS hardware helper for Apple Silicon (M1/M2/M3/M4/M5) and Intel
* Dynamic thermal fan curves and emergency cutoff thresholds
* Clamshell / screen closed detection with automatic native OS auto-restore
* Toast notifications, stacked toasts, and fan limit boundaries
